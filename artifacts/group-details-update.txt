群事件资料补全更新

1. 在服务器实际项目根目录执行在线备份：
   uv run python -m app.cli backup --output "backups/before-group-details-$(date +%Y%m%d-%H%M%S)"
2. 停止当前 Python 服务，然后将本包中的 app/、frontend/ 合并覆盖到实际项目根目录。
   保留服务器 .env、data、backups 和 .venv。本包不包含它们。
3. 在项目根目录执行（3 是当前真实主体 ID）：
   uv run python -m app.cli sync-profiles --tenant-id 3
   该命令需要企微相关接口权限；如果失败请保留错误信息，不要删除数据库。
4. 按原来的方式启动服务，保持单 worker；示例：
   nohup .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1 > uvicorn.log 2>&1 < /dev/null &
5. 强制刷新网页。旧记录缺失的群名若已在当前群资料中存在，会显示为“群名称（当前）”。
6. 资料快照同步成功后，再对经过允许的测试成员执行一次测试操作。

更新内容：
- 对群成员移除事件比较变更前后的群成员列表；只有差异人数与回调一致且无同时新增成员时，才展示候选成员。
- 候选成员复用同一主体内缓存的客户/员工资料。候选身份仍待核实，不计入已确认的客户流失指标。
- 群主单独显示，不能代替本次移除的操作人。
- 历史记录若没有变更前快照，无法通过当前成员列表还原准确离群成员。
- 不需要数据库迁移，不新增依赖，不重新生成密钥。
