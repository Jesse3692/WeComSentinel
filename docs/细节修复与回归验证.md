## 修复内容

1. 会话请求绑定代次；退出与会话失效使旧响应失效，迟到的401不触发新会话重登。主动退出先记录意图、清理本地数据；401视为会话已结束；网络或服务端失败保留重试退出入口，不宣称服务端注销成功。刷新页面也尊重主动退出意图。
2. 会话清理统一关闭详情、恢复滚动、清空数据/游标/员工选项/管理缓存、释放图表与观察器。分页错误检查请求版本。首屏失败不再同时显示暂无数据；分页错误单独提示，刷新失败说明保留旧数据。
3. 群成员资料按缺姓名或头像补全。avatar_state区分stored、not_provided、retry；下载失败进入既有有限重试流程，平台没有提供头像不作为无限重试条件。成员分类和身份依据不因头像失败变化。列表为匹配成员显示头像组，详情逐人显示；未确认候选人不冒用头像。
4. 新增联系人强制刷新客户关系，避免同客户新增员工关系或重加关系沿用五分钟旧缓存。缺少当前关系添加方式时保留partial并重试；强制刷新失败不把缓存添加方式作为当前关系事实。删除事件继续允许历史快照兜底。平台当前资料无法保证还原任意历史关系，应保留未知，不能编造。
5. 群名搜索与显示采用同一规则：历史群名优先，缺失时回退同主体当前群名。数据库查询阶段过滤，保持分页和数量一致；不改写历史快照。
6. 员工选项合并Profile与事件员工ID，按主体+员工ID去重，缺姓名以ID显示；支持姓名/ID检索与offset/limit，前端支持更多员工且保留当前选中项。
7. 管理操作后刷新/me并保留仍合法的当前选择，失效时回退全部授权主体。主体偏好串行保存，旧会话队列跳过；此保证针对当前页面，不承诺不同浏览器标签页的跨客户端排序。
8. 明细接口返回实际生效range；摘要不再依赖旧看板。继续分页使用首屏range，避免午夜默认日期移动导致游标失效；刷新重新取默认范围。事件时间增加年份。
