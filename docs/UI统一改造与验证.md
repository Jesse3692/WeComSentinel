# UI 统一改造与本地验证

日期：2026-10-23。保留 Vue 3 与现有业务事件分类。

## 变更

- API 新增 metrics_range、trend_range，保留 range 兼容字段。默认指标与排名近7天、趋势近30天，自定义日期统一生效。
- 汇总页选择日期，明细继承日期并提供返回调整入口。
- 切换主体同步清理员工筛选；查询变化清理旧结果，同条件刷新保留结果。
- ECharts 复用实例，保留图例选择；颜色从 CSS 计算值读取，按事件类型共用。
- 群列表直接显示可关联成员；证据不足显示成员待核实；系统比对推断明确标注。
- 联系人列表补员工头像；弹窗支持 Escape、焦点约束与恢复、背景滚动锁定，禁用弹窗期间下拉刷新。
- tokens.css 集中管理配色与基础尺寸，展开原压缩样式；PC、平板、手机统一主题。四项事件颜色、环比颜色和状态颜色分开。

## 设计值来源边界

本项目采用 Ding Design 启发的主题。官方网页可返回外壳，但未独立取得官方变量内容，因此不声明严格符合官方规范。#007FFF 为品牌参考，按钮使用 #006AD6 并配更深 hover/active，属于项目可读性调整。字号、间距、圆角均为项目选择。未来取得官方版本资料时仅需对照 tokens.css。

## 验证

- 全量 Python 测试：94 passed；pytest 缓存目录写入告警不影响结果。
- 补充日期范围断言后重跑 tests/test_system.py。
- 前端 TypeScript 校验与 Vite 构建通过；构建仍提示主包超过500kB。
- tests/ui-unification.cjs 使用本地模拟 API，覆盖375、390、428、900、1440px无横向溢出；验证刷新保留画布、主体切换清理员工、明细继承日期、弹窗滚动锁定与Escape/焦点恢复、群成员可见。
- 截图与机器验证结果：artifacts/ui-unification/。

浏览器截图使用明确标注的模拟数据。当前配置关闭演示登录，原 browser-smoke.cjs 在演示密码定位处超时；未修改现有配置，另用独立模拟接口验证。未验证真实钉钉PC/手机容器、平台回调或线上部署。自动刷新复用与手动刷新相同的数据更新路径。

## 复现

运行本地服务后，设置 PLAYWRIGHT_MODULE 指向可用 playwright 模块，执行 node tests/ui-unification.cjs。测试使用 Edge headless，接口全部拦截为模拟数据，不更改业务数据库。截图支持产品评审，真实容器验收另行记录。
