## 1. 产品概述

### 1.1 产品定位

一款部署在钉钉工作台的 H5 应用，自动接入企业微信数据，帮助管理者实时掌握多个主体（企业/子公司/部门）下客户关系的变动情况。

### 1.2 核心价值

> **把「谁加了客户、谁删了客户、谁退了群」从不可见变成一眼可见。**

- 管理者无需登录企业微信后台翻看日志
- 多个主体的数据统一汇总到一个看板
- 异常流失（大量删除/退群）第一时间暴露

### 1.3 目标用户

| 角色 | 典型场景 | 关注点 |
| --- | --- | --- |
| 销售总监 / 运营负责人 | 每天打开钉钉看一眼各团队客户变动 | 汇总数据、趋势、谁流失多 |
| 区域经理 / 团队主管 | 关注自己团队员工的客户增减 | 按员工维度的明细 |
| 客服/社群运营 | 查看群成员的进退情况 | 退群/被踢明细、哪个群在流失 |

### 1.4 使用终端

钉钉移动端 / 钉钉 PC 端 工作台内嵌 H5 微应用。

## 2. 业务范围

### 2.1 统计的四种事件

| 事件类型 | 定义 | 需要记录的信息 |
| --- | --- | --- |
| **新增联系人** | 企业微信员工添加了外部联系人（客户） | 哪个员工添加、客户昵称、客户头像、添加时间、添加方式 |
| **删除联系人** | 企业微信员工删除了外部联系人，或客户删除了员工 | 被删客户昵称、头像、他删除的员工姓名、删除时间 |
| **退群** | 外部联系人主动退出客户群 | 群名称、退群客户昵称、头像、退群时间 |
| **被踢出群** | 外部联系人被管理员/群主移出客户群 | 群名称、被踢客户昵称、头像、操作人、踢出时间 |

### 2.2 多主体说明

支持接入**多个企业微信账号（不同 corpid）**，每个视为一个独立主体。用户可以切换主体查看各自的数据，也可以查看多主体合计。

典型场景：集团下有母公司、子公司 A、子公司 B，各用独立的企业微信账号，需要在同一个看板中分别查看。

## 3. 功能需求

### 3.1 免登登录

| 项目 | 说明 |
| --- | --- |
| 触发时机 | 用户从钉钉工作台点击应用入口 |
| 体验 | 无需输入账号密码，自动识别钉钉身份完成登录 |
| 异常处理 | 非授权用户提示「无访问权限，请联系管理员」 |

### 3.2 汇总看板（首页）

#### 3.2.1 四宫格指标卡

页面顶部展示当前选中主体 + 日期范围内的四项核心指标：

```plaintext
┌──────────────┐  ┌──────────────┐
│  新增联系人   │  │  删除联系人   │
│    128       │  │     15       │
│  ↑ 较上期 +12 │  │  ↓ 较上期 -3  │
└──────────────┘  └──────────────┘
┌──────────────┐  ┌──────────────┐
│    退群      │  │  被踢出群    │
│     42       │  │      8       │
│  ↑ 较上期 +5  │  │  ↓ 较上期 -1  │
└──────────────┘  └──────────────┘

```

每个卡片显示：当前值、较上一周期的变化量（红色上涨/绿色下降）。

#### 3.2.2 趋势图

以折线图展示近 30 天四项指标的变化趋势，四条线颜色不同，支持点击图例切换显示/隐藏某条线。

#### 3.2.3 Top 排名

- **新增 Top 5 员工**：谁加客户最多
- **删除 Top 5 员工**：谁删客户最多
- **退群 Top 5 群聊**：哪些群流失最严重

#### 3.2.4 筛选条件

| 筛选项 | 类型 | 默认值 |
| --- | --- | --- |
| 主体选择 | 下拉单选 | 用户上次选择 |
| 日期范围 | 日期范围选择器 | 近 7 天 |

### 3.3 新增联系人明细

**列表每项展示：**

```plaintext
┌─────────────────────────────────┐
│ [员工头像] 张三                  │
│           添加了                 │
│ [客户头像] 王总                  │
│           2026-07-09 10:30      │
│           扫描二维码  ·  抖音渠道  │
└─────────────────────────────────┘

```

**筛选条件**：主体、员工、日期范围、添加方式

**添加方式枚举**（企微定义）：

- 扫描二维码
- 搜索手机号
- 名片分享
- 群聊添加
- 手机通讯录
- 微信联系人
- 其他

点击列表项可展开完整详情（客户类型、性别、所属企业等）。

### 3.4 删除联系人明细

**列表每项展示：**

```plaintext
┌─────────────────────────────────┐
│ [客户头像] 李经理                │
│           被                      │
│ [员工头像] 赵六 删除              │
│           2026-07-08 15:22       │
└─────────────────────────────────┘

```

**筛选条件**：主体、员工、日期范围

### 3.5 群变更明细

顶部 Tab 切换：「退群」和「被踢出群」。

**退群列表每项：**

```plaintext
┌─────────────────────────────────┐
│ [客户头像] 王总                  │
│           退出了                  │
│           VIP客户服务群           │
│           2026-07-09 11:00       │
└─────────────────────────────────┘

```

**被踢出群列表每项：**

```plaintext
┌─────────────────────────────────┐
│ [客户头像] 张先生                │
│           被 [操作人] 移出        │
│           售后咨询群              │
│           2026-07-09 09:45       │
└─────────────────────────────────┘

```

**筛选条件**：主体、群名称搜索、日期范围

### 3.6 个人中心

- 显示当前钉钉用户头像和姓名
- 显示可访问的主体列表（当前哪些主体有权限查看）
- 退出登录

## 4. 用户权限

| 角色 | 权限 |
| --- | --- |
| **管理员** | 查看所有主体数据，可在后台管理主体配置、管理用户权限 |
| **普通用户** | 仅查看被授权的主体数据 |

授权粒度：按用户 + 主体绑定，一个钉钉用户可以访问一个或多个主体的数据。

## 5. 页面结构与交互流程

### 5.1 信息架构

```plaintext
钉钉工作台入口
    │
    ├── 免登自动登录
    │
    ├── 汇总看板（首页）
    │   ├── 主体切换
    │   ├── 日期筛选
    │   ├── 四宫格指标
    │   ├── 趋势图
    │   └── Top 排名
    │
    ├── 新增明细
    │   └── 筛选 + 分页列表
    │
    ├── 删除明细
    │   └── 筛选 + 分页列表
    │
    ├── 群变更明细
    │   ├── Tab：退群
    │   └── Tab：被踢出群
    │
    └── 个人中心

```

### 5.2 底部导航栏

| Tab | 图标示意 | 名称 |
| --- | --- | --- |
| 1 | 📊 | 汇总 |
| 2 | ➕ | 新增 |
| 3 | ➖ | 删除 |
| 4 | 💬 | 群变更 |
| 5 | 👤 | 我的 |

### 5.3 关键交互规则

- 主体切换后，所有页面数据立即刷新为新主体的数据
- 日期筛选统一放在汇总页顶部，明细页继承汇总页的日期范围
- 明细列表支持**下拉刷新**和**上拉加载更多**
- 列表没有数据时显示空状态占位：「暂无数据」

## 6. 数据来源与更新机制

### 6.1 数据来源

数据由企业微信开放平台通过**回调推送**自动提供，无需人工导入。每个接入的主体需要在企业微信管理后台配置回调地址。

### 6.2 数据时效

| 数据类型 | 更新方式 | 延迟 |
| --- | --- | --- |
| 变更事件 | 企微实时回调 | < 1 分钟 |
| 客户头像 | 回调时同步下载存本地 | 实时 |
| 汇总统计 | 事件写入后实时更新 | < 1 分钟 |

### 6.3 数据补全策略

企微回调仅提供 userid，需通过企微接口补全以下信息：

- 员工姓名、头像
- 客户昵称、头像、类型（微信/企微）、性别、所属企业
- 群名称

## 7. 非功能性需求

### 7.1 性能

| 指标 | 要求 |
| --- | --- |
| 首页汇总数据加载 | < 2 秒 |
| 明细列表首屏 | < 1.5 秒 |
| 明细分页加载 | < 1 秒 |
| 趋势图渲染 | < 2 秒 |

### 7.2 可用性

- 支持钉钉移动端（iOS / Android）和 PC 端
- 适配不同手机屏幕尺寸（375px ~ 428px 宽度）
- 弱网环境下有加载状态提示

### 7.3 安全性

- 所有请求通过 HTTPS
- 免登 token 有过期时间（2 小时），过期自动重新获取
- 不同用户数据按授权隔离
