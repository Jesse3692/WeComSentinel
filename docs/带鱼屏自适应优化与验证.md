# 带鱼屏自适应优化与验证

日期：2026-10-23。目标为公司常用3440×1440带鱼屏，保留常规电脑、手机和现有业务行为。

## 调整

- 1800px起解除主区域1900px且靠左的最大宽度限制，使用侧栏之外的完整工作区，边距随窗口宽度调整，正文/辅助字号及图表标注适当增大。
- 2200px起汇总页采用左侧四项指标与趋势、右侧三类Top5；排名将姓名、主体与人次紧凑对齐，保留完整文字及排名信息。3440×1440模拟样本中三类完整五行排名同时可见。
- 1800px起新增/删除采用客户与关系变化、员工与主体、发生时间的列布局；搜索与员工筛选横向排列，长文本换行，不裁掉身份信息。
- 常规电脑与手机维持原有卡片/上下布局；拖动窗口跨断点更新图表尺寸和文字，保留图例隐藏状态，不重建Canvas。
- 吸底分页跟随列表实际宽度；弹窗、头像、日期、权限和统计口径不变。个人中心在宽工作区居中并控制可读宽度。

## 本地验证

检查覆盖：工作区无右侧大块闲置和横向溢出；宽屏左右布局及常规上下布局；Canvas宽度跟随容器；小屏隐藏曲线后放大到带鱼屏仍隐藏，Canvas保留；明细员工列与标题对齐；吸底栏左右对齐；各尺寸弹窗关闭可见；连续长客户及员工姓名完整展示且不撑开页面。
